T0188 · Execution · TA04 · identified from research/guidance

Cross Site Request Forgery

Code Security

Cross-Site Request Forgery, or CSRF, may have different affects, depending on the application code.
It is widely used in conjunction with spear-phishing attacks where adversaries will attempt to abuse authenticated users sessions to perform actions that will allow them to take over a server.

Mitigations

  • M1720 Implement regular patches and updates
  • M1880 Implement Anti-CSRF token
  • M1881 Enable SameSite cookies
  • M1882 Implement Strict Referer Policy
  • M1883 Implement Web Application Firewall

Detections

  • D1261 Implement penetration testing
  • D1262 Implement vulnerability assessment
  • D1171 Implement Web Application Firewall
  • D1880 Missing Anti-CSRF token
  • D1881 Missing Referer header
