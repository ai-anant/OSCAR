OSC&R / Techniques / T0152

T0152 · Execution · TA04

IDE

Open Source Security

Malicious code can be injected into build commands, build scripts or project files.
These commands and scripts can be executed upon IDE project build and run.

Mitigations

  • M1500 Verify third-party artifacts and open-source libraries
  • M1502 Define trusted package managers and repositories
  • M1503 Implement SCA analysis
  • M1520 Use security scanning tools
  • M1521 Use containerization

Detections

  • D1510 Implement Intrusion Detection System and anti-malware
  • D1520 Implement endpoint detection and response system

Seen in incidents

  • TanStack Mini Shai-Hulud (CVE-2026-45321)
