OSC&R / Techniques / T0122

T0122 · Initial Access · TA03 · observed in 5 incident(s)

Vulnerability in third-party CI/CD actions

CI/CD Posture Container Security Infrastructure as code Open Source Security

The use of 3rd party Github actions is very common.
Similar to using 3rd party libraries this can also introduce security risks - a malicious Github action has access to very sensitive information - i.e exfiltrating environment variables, including backdoors or malware in source code, infecting build artifacts.

Mitigations

  • M1120 Store credentials in vault
  • M1220 Use only trusted third-party Github actions from reputable sources
  • M1221 Review the Github action source code
  • M1222 Limit the permissions granted to third-party Github actions

Detections

  • D1260 Implement regular security audit and review
  • D1261 Implement penetration testing
  • D1262 Implement vulnerability assessment
  • D1590 Implement continuous monitoring and logging of the CI/CD process
