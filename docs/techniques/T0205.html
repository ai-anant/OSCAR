OSC&R / Techniques / T0205

T0205 · Initial Access · TA03 · observed in 3 incident(s)

Compromise third-party CDN or hosted web asset

Open Source Security Artifact Security Cloud Security

Instead of poisoning a package registry or source repository, the attacker
takes over a widely embedded CDN hostname, tag manager, or hosted JavaScript
asset (domain expiry, registrar hijack, or operator acquisition) and serves
malicious content to every site that loads it. Polyfill.io (2024) is the
reference case: a trusted script URL became a drive-by supply-chain implant
for hundreds of thousands of properties. OSC&R previously had no technique
that named this web-asset supply chain.

Where this idea came from

Public incident / advisory

This fork, after Polyfill.io (Sansec) showed CDN/web-asset takeover was unnamed.

  • https://sansec.io/research/polyfill-supply-chain-attack
  • https://www.cisa.gov/news-events/alerts/2024/06/27/widespread-security-compromise-polyfillio-supply-chain-attack

Mitigations

  • M1200 Verify package authenticity
  • M1291 Verify package or container sources
  • M1501 Require SBOM from all third-party suppliers

Detections

  • D1262 Implement vulnerability assessment
  • D1510 Implement Intrusion Detection System and anti-malware

Observed in incidents (3)
