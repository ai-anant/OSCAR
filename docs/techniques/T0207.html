OSC&R / Techniques / T0207

T0207 · Defense Evasion · TA07 · observed in 2 incident(s)

Skip or forge artifact integrity verification

Artifact Security Open Source Security CI/CD Posture

Consumers are supposed to verify packages, containers, and third-party
scripts (checksums, signatures, Sigstore, Subresource Integrity). The
attacker relies on that check never running, or supplies a matching but
attacker-controlled signature. OWASP CICD-SEC-9 names the control gap;
this technique is the attacker side. Polyfill.io hotlinks without SRI and
unsigned CI helper scripts are typical realizations.
