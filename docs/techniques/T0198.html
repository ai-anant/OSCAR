OSC&R / Techniques / T0198

T0198 · Defense Evasion · TA07

Malicious Build Time Dependencies

CI/CD Posture Code Security Open Source Security

Within the CI/CD workflow, code can be pushed at different stages. During the build process, plugins are often utilized for tasks like building and testing. However, if a third-party plugin is compromised, malicious code can be introduced. For instance, an attacker gains control over a Maven plugin (a popular build framework) and inject malware during the build process. SBOM tools may not be effective in detecting such scenarios as they primarily operate on source code.

Mitigations

  • M1200 Verify package authenticity
  • M1220 Use only trusted third-party Github actions from reputable sources
  • M1501 Require SBOM from all third-party suppliers

Detections

  • D1262 Implement vulnerability assessment
  • D1510 Implement Intrusion Detection System and anti-malware

Seen in incidents

  • XZ Utils backdoor
  • Ultralytics PyPI compromise
