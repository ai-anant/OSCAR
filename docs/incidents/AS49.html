AS49 · 2025-11

Sha1-Hulud: The Second Coming

npmGitHub ActionsGit / GitHub

Late November 2025 a second Shai-Hulud wave labeled itself in exfil
repos as "Sha1-Hulud: The Second Coming" (Socket). Execution moved to
preinstall, widening blast radius on developer machines and CI. New
payloads setup_bun.js and bun_environment.js. A destructive fallback
could wipe the user’s home directory. Hundreds of packages again, plus
tens of thousands of attacker-created GitHub repositories. StepSecurity
later noted detection inside CNCF Backstage.

Mapped OSC&R elements

  • T0151 Installation scripts
  • T0109 Publish malicious artifact
  • T0168 Exfiltration to code repositories
  • T0169 Push implants across repositories
