OSC&R / Incidents / AS4

AS4 · 2021-03

PHP Zerodium Backdoor

Packagist / Composer

In March 2023 it was discovered that a bad actor succeeded to infect the official PHP code with a backdoor. PHP is one the most common technologies for web applications - a successful attack would have meant taking over millions of servers.

Mapped OSC&R elements

  • T0195 Spoofed Commits
  • T0137 Weak authentication methods
  • T0180 Compromise services / servers
  • T0191 Malicious code in artifacts
  • T0172 Runtime backdoor
  • T0111 Malicious code contribution to an open-source repository

supply-chain PHP Zerodium Backdoor

T0195 · Defense Evasion · Spoofed Commits

The attackers tried to impersonate two PHP developers

T0137 · Reconnaissance · Weak Authentication Methods

As part of the action items after the breach was to enable MFA

T0180 · Initial Access · Compromise Services / Servers

PHP Git server was maintained by the PHP developers. After the breach they decided to move to Github.

T0191 · Impact · Malicious Code In Artifacts

On March 28th, 2021, two commits to the source code of PHP were more than extraordinary. They contained a backdoor which would execute if HTTP_USER_AGENT string starts with 'zerodium'.

post-supply-chain PHP Users

T0172 · Execution · Runtime Backdoor

The backdoor would execute commands when a HTTP request with User-Agent 'zerodium' was sent

T0111 · Resource Development · Malicious Code Contribution To An Open-Source Repository
