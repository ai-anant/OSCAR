AS32 · 2026-09

WeaselBiscuit npm import-time stealer

npm

OpenSourceMalware documented WeaselBiscuit, a stripped-down JS stealer
overlapping DPRK Contagious Interview tooling (BeaverTail/OtterCookie).
Thirteen npm packages delivered it. A detached Node child loads a payload
from an Npoint dead drop and runs it in memory. It profiles the host and
uploads Chrome extension LevelDB wholesale. No disk persistence, no RAT.
Several packages were still live on npm at publication.
