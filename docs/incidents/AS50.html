OSC&R / Incidents / AS50

AS50 · 2026-07

Miasma botnet loader in @asyncapi npm packages

npm

On 14 July 2026 Socket found four compromised @asyncapi packages
(generator-helpers 1.1.1, generator-components 0.7.1, generator 3.3.1,
specs 6.11.2) shipping a hidden JS implant. Not an install-hook attack:
loading the module in Node starts a detached node -e process that
downloads an encrypted Miasma second stage from IPFS. Same implant
decoded from each injected file. Preceding versions were clean.
