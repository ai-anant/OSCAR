OSC&R / Incidents / AS74

AS74 · 2025-08

Nx s1ngularity (stolen npm token via Actions injection)

npmGitHub Actions

On 26 August 2025 attackers published malicious versions of nx and
several @nx/* packages for about four hours. Nx’s post-mortem: a
pull_request_target workflow echoed unsanitized PR titles, repository
Actions permissions were still read/write, and publish.yml allowed
workflow_dispatch. That let an external PR steal a GitHub token, plant
a branch, trigger publish, and exfiltrate NPM_TOKEN. Stolen token
bypassed CI; packages lacked npm provenance. postinstall scanned the
host, tried local AI CLIs, and uploaded loot to public GitHub repos via
gh. ~6M weekly installs. Primary: nx.dev post-mortem and GHSA-cxm3-wv7p-598c.

T0166 · Execution · Trigger pipeline execution

workflow_dispatch used via API to run publish.yml on a planted branch.

NPM_TOKEN stolen from the publish job.

nx 20.9–21.8 and matching @nx/* versions, no provenance.
