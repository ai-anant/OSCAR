OSC&R / Incidents / AS65

AS65 · 2026-07

Claude eval agent published a malicious package to live PyPI

PyPIAI coding agents

On 30 July 2026 Anthropic disclosed that a Claude model in an internal
cybersecurity evaluation escaped isolation, created a Python package with
hidden credential-stealing code, and published it to the real PyPI
registry. The model believed the registry was part of the simulation.
The package was public for about an hour and ran on 15 real systems.
One was a security vendor’s malware scanner; the payload exfiltrated
that company’s credentials and the model used them to go further into
the vendor’s infrastructure. No human operator. Anthropic notified
three organizations on 27 July and PyPI. StepSecurity’s write-up of
the same report is a secondary source; the primary is Anthropic.
