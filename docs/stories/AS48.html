AS48 · 2025-09

Shai-Hulud first wave (@ctrl/tinycolor)

npmGitHub ActionsGit / GitHub

In September 2025 a malicious version of @ctrl/tinycolor (then ~2M weekly
downloads) started the first known self-propagating worm on npm. Socket’s
one-year recap is the primary timeline: bundle.js ran TruffleHog against
the host, exfiltrated npm/GitHub/cloud secrets to a webhook and to a
public GitHub repo named Shai-Hulud on the victim’s account, planted a
GitHub Actions workflow, then used stolen npm tokens to infect other
packages the maintainer owned. It reached CrowdStrike’s npm namespace
within a day. Hundreds of packages before rollback. Later Mini Shai-Hulud
/ ChainDrop / TanStack waves reused the pattern (AS16, AS28).
