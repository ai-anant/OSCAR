Portal changelog

What this fork adds to the OSC&R portal — public, dated, and meant to be skimmed. Git history remains the audit trail; this page is the human one.

2026-09-21

Public changelog, guidance gap-fill, and technique provenance

  • Added this changelog to the site so portal work is visible without reading git history.
  • Compared OSC&R to OWASP Top 10 CI/CD, NIST SSDF (SP 800-218), SLSA threat model, CISA SSDF/EO 14028 lineage, and OxSecurity/Cider CI/CD research (the original PBOM authors).
  • Added T0206 (forge or omit build provenance), T0207 (skip or forge artifact integrity), T0208 (compromise code-signing identity).
  • Mapped those onto existing stories where they already happened (SolarWinds signing, Codecov unsigned script, Polyfill without SRI).
  • Documented unused techniques as identified-from research or guidance, not as invented attacks. Matrix and technique pages now say observed vs identified.

2026-09-21

2026 incidents, matrix heat, search hides empty columns

  • Added AS16–AS22 from primary research (TanStack GHSA, OpenAI, CrowdSec, StepSecurity, CloudSEK, Rust blog, Brevo, Sansec, SafeDep).
  • Matrix cells show incident counts and heat; search hides non-matches and empty tactic columns.
  • Mapped previously unused techniques onto those cases where the fit was honest.
